NCAA Football 10 Translator

Experimental developer tool. The tested NCAA US disc is currently rejected with an unsupported encryption tag. This tool exports build inputs, not a playable browser engine. To play, use a prepared NCAA web package and its ISO picker.

Turns your NCAA Football 10 PSP (ULUS10440) ISO into the decrypted executable and the generated C++ the build compiles, entirely in this browser. Nothing is uploaded.

Choose your ISO

The page checks the title, decrypts EBOOT.BIN, requires the exact verified executable, then runs the PSPRecomp code generator (compiled to WebAssembly) and extracts the EA audio programs, the same steps as scripts/generate.sh.

Choose an ISO to begin.

  3. Import that package in the launcher.
