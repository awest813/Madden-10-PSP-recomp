NCAA Football 10 Launcher

Runs your own NCAA Football 10 PSP (ULUS10440) web build with your own ISO. This site hosts no game code or disc data.

Preparing browser support…

1. Import your build

Build NCAA from source, then run python scripts/prepare_static_ncaa.py --output build/static-ncaa10. Choose that folder. Every file is checked against its static-manifest.json and kept in this browser, so you only import it once per build.

Checking for an imported build…

Players using a prepared static game site only need its ISO picker. This source-only site is an optional build importer.

Developer tools

The experimental translator exports build inputs and currently rejects the tested NCAA disc's encryption tag. It cannot create or launch a playable web build by itself; a native build toolchain is still required.

2. Launch and choose your ISO

The game page asks for an uncompressed NCAA Football 10 PSP US ISO and checks its title and executable revision against your build. The ISO is read locally in ranges and is never uploaded; choose it again after each reload.

Saves stay in this browser for this site; use Export saves in the game page to back them up. Import only packages you built yourself. How this works.
